# C# 전환 기능 체크리스트

Java 8.1.0 의 모든 기능. 단계마다 C# 버전에서 같은 동작을 확인하고 체크한다.
"호환" 표시가 있는 항목은 Java 버전과 **결과가 똑같아야** 한다 (자동 테스트로 확인).

## 1단계: 핵심 로직 (Atbash.Core)

- [ ] 아트배쉬 (호환)
- [ ] 모스 부호, 자동 감지 (호환)
- [ ] 이진수, 자동 감지 (호환)
- [ ] 카이사르 암호화/복호화, 이동 값 (호환)
- [ ] 스퀴탈레 암호화/복호화, 지름 (호환)
- [ ] 비즈네르 암호화/복호화, 키워드 (호환)
- [ ] AES 텍스트 암호화/복호화, 비밀번호 (호환: Java 암호문을 C#이, C# 암호문을 Java가 풀 수 있어야 함)
- [ ] Base64 / Hex / URL 인코딩·디코딩, ROT13 (호환)
- [ ] 한글 자모 암호 암호화/복호화 (호환)
- [ ] AES 파일 암호화/복호화 `.enc` (호환: 양방향)
- [ ] 안전 삭제 (무작위 데이터로 덮어쓴 뒤 삭제)
- [ ] 버전 비교, version.json 읽기

## 2단계: 기본 화면

- [ ] 원본 텍스트 / 변환된 텍스트 영역, 둥근 모서리
- [ ] 변환 방식 목록 20종 (순서 = 저장된 cipherMode 번호와 같게)
- [ ] 이동 값 / 지름 / 키워드 / 비밀번호 입력칸이 방식에 따라 바뀜
- [ ] [변환] 버튼: 글자가 하나씩 나타나는 애니메이션
- [ ] 실시간 변환 모드 (AES 제외)
- [ ] [복사] + "복사됨!" 사라지는 효과, 빈 결과 복사 시 "LOL" (이스터 에그)
- [ ] [초기화]
- [ ] 언어 4종 (한국어, English, 日本語, 中文), 빠진 번역은 영어로
- [ ] 확인/취소/예/아니요 버튼도 선택한 언어로
- [ ] 라이트 / 다크 테마
- [ ] 창 크기 기억

## 3단계: 파일 기능

- [ ] 불러오기 (UTF-8 텍스트)
- [ ] 저장 (UTF-8)
- [ ] 이미지로 저장 (결과 텍스트를 PNG로, 현재 테마 색)
- [ ] 이미지에서 텍스트 읽기 (OCR, 한국어+영어, 흑백·2배 확대 전처리)
- [ ] 클립보드 이미지에서 텍스트 읽기 (Ctrl+Shift+V)
- [ ] 입력창에서 Ctrl+V 로 이미지 붙여넣기 → OCR
- [ ] 드래그 앤 드롭: 이미지→OCR, .enc→복호화, 텍스트→불러오기, 그 밖→암호화 제안
- [ ] 파일 암호화 (여러 개, 비밀번호 강도 표시) + 원본 안전 삭제 제안
- [ ] 파일 복호화 (여러 개, 덮어쓰기 확인)
