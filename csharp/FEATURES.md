# C# 전환 기능 체크리스트

Java 8.1.0 의 모든 기능. 단계마다 C# 버전에서 같은 동작을 확인하고 체크한다.
"호환" 표시가 있는 항목은 Java 버전과 **결과가 똑같아야** 한다 (자동 테스트로 확인).

## 1단계: 핵심 로직 (Atbash.Core) ✅

Java 결과 6,930개와 100% 일치 (GoldenTests), AES 는 Java↔C# 양방향 확인 (AesTests).

- [x] 아트배쉬 (호환)
- [x] 모스 부호, 자동 감지 (호환)
- [x] 이진수, 자동 감지 (호환)
- [x] 카이사르 암호화/복호화, 이동 값 (호환)
- [x] 스퀴탈레 암호화/복호화, 지름 (호환)
- [x] 비즈네르 암호화/복호화, 키워드 (호환)
- [x] AES 텍스트 암호화/복호화, 비밀번호 (호환: Java 암호문을 C#이, C# 암호문을 Java가 풀 수 있어야 함)
- [x] Base64 / Hex / URL 인코딩·디코딩, ROT13 (호환)
- [x] 한글 자모 암호 암호화/복호화 (호환)
- [x] AES 파일 암호화/복호화 `.enc` (호환: 양방향)
- [x] 안전 삭제 (무작위 데이터로 덮어쓴 뒤 삭제)
- [x] 버전 비교, version.json 읽기

## 3단계: 파일 기능 ✅

가짜 창(FakeDialogs)으로 흐름 전체를 자동 테스트, OCR 은 실제 Tesseract 로 한국어+영어 인식 확인.
개선: 비밀번호가 틀리면 결과 파일을 만들지 않음, 여러 .enc 파일을 한 번에 복호화, OCR 후 "텍스트를 읽었습니다!" 표시(Java 는 "복사됨!"으로 잘못 표시), 덮어쓰기 안내의 ''따옴표'' 정리, UTF-8 이 아닌 파일은 깨진 글자 대신 오류 안내.
실제 OS 동작(파일 선택 창, 탐색기에서 끌어다 놓기, 실제 클립보드)은 사람이 확인 필요.

- [x] 불러오기 (UTF-8 텍스트)
- [x] 저장 (UTF-8)
- [x] 이미지로 저장 (결과 텍스트를 PNG로, 현재 테마 색)
- [x] 이미지에서 텍스트 읽기 (OCR, 한국어+영어, 흑백·2배 확대 전처리)
- [x] 클립보드 이미지에서 텍스트 읽기 (Ctrl+Shift+V)
- [x] 입력창에서 Ctrl+V 로 이미지 붙여넣기 → OCR
- [x] 드래그 앤 드롭: 이미지→OCR, .enc→복호화, 텍스트→불러오기, 그 밖→암호화 제안
- [x] 파일 암호화 (여러 개, 비밀번호 강도 표시) + 원본 안전 삭제 제안
- [x] 파일 복호화 (여러 개, 덮어쓰기 확인)

## 4단계: 부가 기능 ✅

자동 테스트 13개 + 창 이미지(변환 기록, 테마 색, QR, 검색 결과, 스플래시) 확인.
QR 은 만든 이미지를 다시 해독해서 원문(한글·이모지)과 같은지 확인. Java 가 내보낸 .theme 파일 가져오기 확인.
개선: 네이버 검색 결과를 JSON 으로 제대로 읽어 따옴표·&quot; 같은 표기가 깨지지 않음, 검색 결과가 없을 때 알맞은 안내, 이미지 원본을 못 받으면 미리보기 그림으로 OCR.
네이버 실제 API 호출은 사람이 확인 필요 (테스트는 가짜 응답 사용).

- [x] 변환 기록 (Ctrl+H, 최근 50개, 메모리에만, 불러오기·결과 복사·모두 지우기)
- [x] QR 코드로 저장 (미리보기, PNG, 너무 길면 안내)
- [x] 네이버 검색 결과 불러오기 (여러 개 선택)
- [x] 네이버 이미지 검색 후 OCR
- [x] 네이버 API 키: 내장 키 → 저장된 키 → 사용자에게 물어봄
- [x] 사용자 테마: 만들기(색 5개), 선택, 삭제, 내보내기/가져오기 `.theme` (호환: Java Properties 형식)
- [x] 설정 저장 켜기/끄기
- [x] 도움말 → 정보 (README, 클릭하면 이스터 에그 링크)
- [x] 시작 스플래시 (startup.png + 진행 막대)
- [x] 앱 아이콘

## 5단계: 설정·업데이트 ✅

Java 가 레지스트리에 실제로 저장한 이름·값(한글·이모지·대문자·슬래시 포함)을 그대로 되돌리는지 확인 (TestData/java-prefs-registry.json).
업데이트는 시험용 version.json(file: 주소)으로 자동 설치·지문 검사·하루 한 번·건너뛰기·오프라인까지 확인.
설정 옮기기는 C# 설정 파일이 없을 때 처음 한 번만 함.

- [x] Java 설정 가져오기 (레지스트리 HKCU\Software\JavaSoft\Prefs\<unnamed>):
      theme, language, cipherMode, caesarShift, scytaleDiameter, hangulShift, livePreview,
      saveSettingsEnabled, windowWidth/Height, custom.themes.list, custom.theme.*,
      naverClientId/Secret, skippedVersion, lastUpdateCheck
